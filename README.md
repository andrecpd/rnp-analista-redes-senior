# RNP — Analista de Redes Sênior

Projeto de estudos e laboratório para preparação técnica da vaga de **Analista de Redes Sênior — RNP**.

## Objetivos
- Revisar fundamentos de redes, IPv4/IPv6 e subnetting.
- Dominar troubleshooting de routing e switching.
- Revisar OSPF, BGP, MPLS/VRF e alta disponibilidade.
- Praticar Linux e ferramentas de diagnóstico.
- Treinar monitoramento, observabilidade e análise de incidentes.
- Simular uma prova técnica de 2 horas, sem consulta.
